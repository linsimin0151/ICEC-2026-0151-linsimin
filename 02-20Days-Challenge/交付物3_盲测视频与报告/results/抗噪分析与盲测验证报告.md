# 抗噪分析与盲测验证报告

项目三 · 基于手机内置传感器的日常旋转机械异常声振诊断仪

## 1. 系统与数据

- 采集设备：智能手机内置麦克风（48 kHz / 320 kbps 立体声录音），无任何外接传感器，成本 ≈ 0；
- 对象：家用小风扇，5 种工况（W1 关闭 / W2 1挡 / W3 3挡 / W4 扇叶失衡（皮筋搅乱扇叶模拟） / W5 全遮挡出风口）；
- 训练数据：每工况 15 组、每组 5~8 s，共 75 组；另将第二时段补录的 W1/W2 各 3 组纳入训练（共 81 组），用于提升多时段鲁棒性；
- 统一解码为 16 kHz 单声道 WAV 后分析。

## 2. 特征工程与抗噪设计

核心思想：**用"相对量/形态量"替代"绝对量"，使识别不依赖录音音量与手机距离。**

| 特征类别 | 特征 | 抗噪机理 |
|---|---|---|
| 时域 | RMS、峰值 | 反映整体能量水平（对音量敏感，仅作辅助） |
| 时域 | 波峰因子、峭度 | 冲击型异常（失衡拍打）的形态指标，对稳态增益不敏感 |
| 时域 | 过零率 | 频谱重心的粗测度 |
| 频域 | 6 频带能量**占比** | 归一化后与绝对音量无关，只看能量"搬家" |
| 频域 | 频谱熵、平坦度 | 宽带湍流噪声 vs 离散谐波结构的形态差异 |
| 频域 | 主频、次峰 2/3 频率 | 区分"低频嗡声型"与"中频音调型"噪声源 |
| 频域 | 频谱质心 | 负载变化导致的频谱整体迁移 |

Welch 平均周期图（2048 点窗、50% 重叠）在降低随机噪声方差的同时保留谐波峰；
提取前去除直流偏置，避免手机录音的 DC 分量污染过零率与低频特征。

## 3. 训练策略：数据增强

手机自动增益（AGC）与环境噪声本底随时段波动，导致同一工况不同时段的特征分布漂移
（实测同一房间"风扇关闭"的三次录音：47Hz 嗡声占比 92% → 50% → 仅 10%，音量相差 11 倍）。
为此对 81 组训练音频做波形级增强（每段 3 副本，共 324 行训练样本）：

1. **随机增益**（0.1~10 倍，对数均匀）：模拟 AGC 音量漂移；
2. **随机增益 + 真实房间噪声注入**（SNR 0~15dB）：模拟"特征音被环境噪声稀释"；
3. **原音量 + 真实房间噪声注入**（SNR 0~12dB）：模拟高噪声环境。

噪声池取自另一时段的纯背景录音（不与任何盲测样本重叠），相比合成白噪声更贴近真实频谱结构。

## 4. 盲测验证

### 4.1 正式盲测（结果见 blind_test_report.csv）

- 盲测集：15 段模型从未见过的新录音（W1 为第三时段补录，W2 为第二时段重录，W3~W5 为第二时段录音）；
- **结果：12/15 = 80.0%**；
  - W2 / W3 / W4 / W5：**12/12 全部正确**（多数置信度 > 0.75）；
  - W1（风扇关闭）：0/3，全部误判为 W5（置信度 0.90~0.99）。

### 4.2 W1 失败原因分析（本项目最有价值的发现）

对三次不同时段录制的"风扇关闭"音频做频带占比对比：

| 录音时段 | 0-100Hz | 100-300Hz | 300-800Hz | 主频 | 音量(RMS) |
|---|---|---|---|---|---|
| 训练集（第 1 时段） | **92.3%** | 6.9% | 0.7% | 46.9 Hz（电源嗡声） | 0.019 |
| 第 2 时段（归档对照） | 49.0% | 17.9% | 12.3% | 46.9 Hz | — |
| 第 3 时段（盲测 W1） | 9~10% | **57~62%** | 25~28% | **273.4 Hz** | 0.006~0.007 |

结论：

1. 训练集 W1 的判别性特征是 46.9Hz 电源嗡声（风扇插电未开时变压器噪声，当时手机贴近风扇，
   嗓声占比高达 92%）；后续时段房间背景噪声变化（出现 273Hz 中频音调、嗡声占比跌至 10%），
   导致"风扇关闭"的声音指纹在时段间**完全不重叠**；
2. 误判为 W5（全遮挡）的原因：W5 同样是"低/中频主导的安静信号"，与第 3 时段的房间噪声
   频谱形状高度相似——模型输出 0.99 的置信度恰恰说明它对"声音像什么"的判断是自洽的，
   错在训练分布没有覆盖该时段的背景噪声；
3. 即便加入真实噪声增强与多时段训练数据，也无法凭空合成训练中从未出现的 273Hz 音调成分。

### 4.3 对照实验：跨环境泛化测试（blind_crossenv_report.csv）

在正式盲测之前，曾用另一时段的 15 段录音做过一次完整盲测：

- 初始版本 40.0%（后发现并修复特征归一化 bug：训练特征按 int16 量级、盲测按归一化量级，
  相差 3 万余倍——该 bug 的发现过程本身说明盲测环节的必要性）；
- 修复后 66.7%（W3~W5 9/9 全对，W1/W2 失败）；
- 该组数据归档于 `data/blind_crossenv/`，作为抗噪分析的对照证据。

### 4.4 鲁棒性改进轨迹（迭代记录）

| 版本 | 改动 | 盲测准确率 |
|---|---|---|
| v1 | 原始 15 特征 | 40.0% |
| v2 | 修复归一化 bug | 66.7% |

## 5. 结论与工程启示

1. 手机麦克风 + 频带占比/形态类特征可在极低成本下实现风扇运行工况识别，
   **运行类工况（W2~W5）跨时段盲测 100%**；
2. "关闭/背景噪声"类是**非平稳类**：其声音指纹由当时房间内的其他噪声源决定，
   跨时段不可复现——这是所有基于环境声的检测系统都面对的本质困难；
3. 工程对策（本报告已实践部分）：多时段采样、真实噪声增强、特征归一化（相对量替代绝对量）；
   进一步对策：部署前进行一次性环境标定、或采用"检测风扇谐波是否存在"的异常检测框架
   替代固定类别分类；
4. 后续可扩展：更多故障类型（轴承磨损）、多环境迁移学习、端侧部署（ESP32 + FFT 实时推理）。
