# 项目三 · 基于手机内置传感器的日常旋转机械异常声振诊断仪

以普通家用小风扇为对象，仅用**智能手机麦克风**采集 5 种工况下的声振信号，
通过 FFT 频谱特征 + 随机森林实现工况自动识别，验证"低成本非侵入式异常检测"的可行性。

## 5 种工况定义

| 编号 | 工况 | 物理意义 |
|---|---|---|
| W1 | 关闭（背景噪声基准） | 环境本底噪声对照 |
| W2 | 1 挡正常 | 低速健康基准 |
| W3 | 3 挡正常 | 高速健康基准 |
| W4 | 扇叶失衡（皮筋搅乱扇叶模拟） | 不平衡+附加摩擦 → 转频/叶频谐波能量变化 |
| W5 | 全遮挡出风口 | 过载故障 → 电机负载加重，频谱向低频移动 |

每种工况 15 组录音，每组 5~8 秒，共 **75 组**（另有第二时段补录的 W1/W2 各 3 组
参与训练，用于多时段鲁棒性验证）。原始录音（mp3）与现场照片存于
`W1~W5` 文件夹，解码后的标准 WAV（16 kHz 单声道）存于 `data/wav/`。

## 目录结构

```
├── W1~W5/                 原始 mp3 录音 + 现场实验照片（考核交付物①原始数据）
├── data/wav/              81 组标准 WAV（由 01 脚本生成，含第二时段补录）
├── data/blind/            正式盲测样本（新录、模型从未见过）
├── data/blind_crossenv/   跨环境泛化对照实验数据（归档）
├── features/features.csv  特征表：81 样本 × 17 特征
├── features/features_aug.csv  增强后训练表：324 行（81 原始 + 243 增强）
├── code/
│   ├── 01_convert_to_wav.py    mp3 -> 16kHz 单声道 WAV
│   ├── 02_extract_features.py  时域(RMS/峰值/波峰因子/过零率/峭度)
│   │                           + 频域(Welch: 主频/次峰2·3/质心/熵/平坦度/6频带能量占比)
│   ├── 02b_augment_features.py 数据增强：随机增益 + 真实房间噪声注入(SNR 0~15dB)
│   ├── 03_train_classify.py    随机森林 5 折交叉验证 + 混淆矩阵/频谱对比/特征重要性图
│   └── 04_blind_test.py        盲测脚本：对新录音输出预测与准确率
└── results/               图表、盲测报告、抗噪分析与盲测验证报告
```

## 运行顺序

```bash
python code/01_convert_to_wav.py
python code/02_extract_features.py
python code/02b_augment_features.py
python code/03_train_classify.py
# 盲测音频放入 data/blind/ 后：
python code/04_blind_test.py
```

## 主要结果

- **训练集分层 5 折交叉验证准确率：97.5% ± 3.1%**（含多时段数据，见图 results/confusion_matrix.png）；
- **正式盲测准确率：80.0%（12/15）**——运行类工况 W2~W5 **12/12 全对**，
  仅"风扇关闭"(W1) 因房间背景噪声跨时段非平稳而误判（详见 results/抗噪分析与盲测验证报告.md）；
- 频谱物理特征清晰可解释：
  - W4 扇叶失衡：中高频段（>1 kHz）谐波簇能量明显抬升（皮筋扰动产生高频湍流）；
  - W5 全遮挡：负载加重，频谱能量向中低频集中；
  - W2/W3 档位差异体现在主频与整体能量水平；
- 抗噪迭代轨迹：盲测 40% → 66.7% → 80%（修复归一化 bug、去直流、数据增强、多时段数据），
  完整失败分析见报告第 4 节。

## 技术要点

- 采样链路：手机录音 48 kHz/320 kbps → ffmpeg 解码重采样 16 kHz 单声道；
- 抗噪设计：特征中包含频带能量**占比**与频谱熵等相对量，降低绝对音量敏感性；
- 分类器：RandomForest(200 树)，特征标准化，分层 5 折交叉验证防过拟合评估；
- 全流程（录音→特征→训练→盲测）均可在消费级手机 + 普通 PC 复现，成本≈0。

## AI 使用说明
